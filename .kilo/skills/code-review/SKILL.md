# Код-ревью перед мержем

## Порядок работы
1. Запустить `make test`, убедиться, что проходит.
2. Запустить `make lint`, убедиться, что проходит.
3. Проверить код на грубые ошибки: утечка секретов — ключи, пароли, ПДн в коде или репозитории.
4. Не править код самому: ревьюер только отмечает проблемы, не исправляет.

## Формат результата
Список замечаний, оформленный маркированным списком.

## Чек-лист
- `make test` проходит
- `make lint` проходит
- Утечки секретов нет: ключи, пароли, ПДн не попадают в код или репозиторий
- Код при ревью не правится самим ревьюером
